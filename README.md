# Sakura Apps Portfolio

GitHub Pages にそのまま置ける静的サイトです。

## ファイル
- `index.html` … トップページ
- `privacy.html` … プライバシーポリシー
- `style.css` … デザイン
- `script.js` … スマホメニューなど
- `assets/favicon.svg` … ブラウザのタブ用アイコン
- `assets/ogp.svg` … SNSシェア用画像

## 最初に変更するところ
1. `index.html` の各 App Store ボタンの `href="#"` を実際のURLに変更
2. X / Instagram の `href="#"` を実際のURLに変更
3. `YOUR_EMAIL@example.com` を問い合わせ用メールアドレスに変更
4. アプリ説明・プロフィール文を必要に応じて変更
5. `privacy.html` を、実際に使っている広告・解析SDKに合わせて調整

## GitHub Pages 公開
リポジトリに全ファイルをアップロードし、Settings → Pages → Deploy from a branch で main / root を選択します。
